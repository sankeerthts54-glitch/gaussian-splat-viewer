01 — The Concept

What is Gaussian Splatting?

3D Gaussian Splatting (3DGS) is a breakthrough in neural rendering that represents 3D scenes as millions of tiny, semi-transparent 3D ellipsoids — each one a Gaussian with a position, shape, opacity, and view-dependent color. Unlike meshes or voxels, these soft primitives can capture fine details like fur, glass, and fog with stunning fidelity.

Step 1

Point Cloud

Structure-from-Motion (COLMAP) analyzes overlapping photos to triangulate a sparse 3D point cloud and recover camera poses.

Step 2

Gaussian Optimization

Each point becomes a 3D Gaussian — an ellipsoid with learnable position, covariance (shape), opacity, and spherical harmonic color coefficients. A differentiable renderer optimizes all parameters via gradient descent.

Step 3

Real-Time Rendering

A GPU rasterizer sorts Gaussians by depth, projects them as 2D ellipses, evaluates view-dependent color from spherical harmonics, and alpha-composites them at 60+ FPS.

03 — The Pipeline

How We Built This

From raw images to a real-time web experience — here's every step of the journey.

01

Image Capture

100 synthetic views rendered from a Blender Lego model at multiple angles, providing complete 360° coverage of the scene.

Blender · Synthetic Dataset
02

Structure from Motion

COLMAP analyzes feature correspondences across image pairs to triangulate a sparse 3D point cloud and recover precise camera extrinsics and intrinsics.

COLMAP · Feature Matching · Bundle Adjustment
03

Gaussian Splatting Training

Nerfstudio's splatfacto method initializes 3D Gaussians from the point cloud and optimizes position, covariance, opacity, and SH color coefficients over 30,000 iterations using a photometric loss.

nerfstudio · splatfacto · gsplat · CUDA
04

Export & Compression

The trained model checkpoint is exported to a .ply point cloud (824 MB), then converted to the compact .ksplat binary format (80 MB) — a 10× compression optimized for web streaming.

Custom Python Export · GaussianSplats3D Converter
05

Web Viewer

The .ksplat file is loaded in-browser by a WebGL-based renderer that sorts Gaussians by depth each frame and alpha-composites them in real-time using a custom shader.

Three.js · GaussianSplats3D · WebGL 2.0

05 — The Math

Under the Hood

The elegance of Gaussian Splatting lies in three core mathematical concepts that make it both beautiful and blazingly fast.

3D Gaussian Representation

Each Gaussian is parameterized by a mean (position) μ and a 3×3 covariance matrix Σ that defines its shape as an ellipsoid:

G(x) = e-½ (x-μ)T Σ-1 (x-μ)

The covariance Σ is decomposed as RSSTRT where R is a rotation matrix and S is a diagonal scale matrix — ensuring the covariance is always positive semi-definite.

Spherical Harmonics Color

Instead of storing a single RGB color, each Gaussian stores spherical harmonic (SH) coefficients that encode view-dependent appearance:

c(d) = Σl=0L Σm=-ll clm · Ylm(d)

This lets the model capture specular highlights and reflections that change as you orbit the scene — the same Gaussian can appear different colors from different viewing directions.

Alpha Compositing

The final pixel color is computed by front-to-back alpha compositing of all Gaussians overlapping that pixel, sorted by depth:

C = Σi=1N ci · αi · Πj=1i-1(1 - αj)

Each Gaussian's contribution is weighted by its own opacity αi and the accumulated transmittance — how much light has passed through all closer Gaussians without being absorbed.
